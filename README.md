# Лабораторная работа по ООП: редактор фигур на Qt с базой SQLite.

- На сцену добавляются эллипс, прямоугольник и правильный многоугольник с заданными размерами.
- Фигуры можно связывать линиями. Линии следуют за фигурами при перетаскивании.
- Каждая фигура хранится в SQLite: id, тип, id связанных фигур и количество фигур этого типа.
- Таблица показывает базу. Её можно фильтровать по id, типу и количеству, база при этом не меняется.
- Выбранную фигуру можно удалить из таблицы или со сцены.

## Что нужно

- Qt 6 с модулями Widgets и Sql (драйвер QSQLITE входит в Qt);
- qmake;
- компилятор с поддержкой C++17.

## Сборка и запуск

```bash
service_scripts/run.sh
```

Скрипт собирает программу в `build/` и запускает окно. База `qt-paint.db` создаётся рядом с программой и при каждом запуске начинается пустой.

Собрать без скрипта:

```bash
mkdir -p build && cd build && qmake ../qt-paint.pro && make && ./qt-paint
```

## Как пользоваться

| Действие | Как |
|---|---|
| Добавить фигуру | Выбрать тип и размеры слева, нажать "Добавить" |
| Связать две фигуры | Нажать "Связь", кликнуть первую фигуру, затем вторую. Esc или клик мимо - отмена |
| Переместить фигуру | Перетащить мышью |
| Отфильтровать таблицу | Поля над таблицей |
| Удалить фигуру | Выделить её строку в таблице и нажать "Удалить выбранную" |
